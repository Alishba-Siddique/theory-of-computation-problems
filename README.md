# Theory of Computation — MIT OCW 18.404J Problem Sets

Worked solutions to the problem sets from MIT OpenCourseWare 18.404J 
"Theory of Computation" (Fall 2020), taught by Prof. Michael Sipser.

All problems are taken from Sipser, M. *Introduction to the Theory of 
Computation*, 2nd edition (Thomson Course Technology, 2006).

Course materials: https://ocw.mit.edu/courses/18-404j-theory-of-computation-fall-2020/

## Topics covered

- **Problem Set 1:** Finite automata, regular expressions, regular languages
- **Problem Set 2:** Properties of regular languages, the pumping lemma, non-regular languages
- **Problem Set 3:** Context-free grammars and languages, pushdown automata
- **Problem Set 4:** Turing machines, decidability, the Church-Turing thesis
- **Problem Set 5:** Reducibility, undecidability, the recursion theorem
- **Problem Set 6:** Time complexity, the class NP, NP-completeness
